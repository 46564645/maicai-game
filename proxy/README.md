# 家长站 AI 对话中转代理（公开网页版专用）

业主 2026-11-19 拍板搭建。背景与红线见 `../PARENT_API_R7.md`；本目录是
R7 的公开版补丁：**key 绝不进网页前端**——网页里只写代理地址，真 key
只存在于函数计算的环境变量中，由代理转发时注入。

> 注：仓库 AGENTS.md 的「不要引入后端/网络请求/真实 AI」一条，已被业主
> 本人自 R7 起明确覆盖（先直连、后代理），与 parentLive.ts 文件头记录一致。

## 组成

- `fc-index.cjs`（部署时粘贴为函数的 `index.js`）：阿里云函数计算 FC 的事件函数（Node.js 18，零依赖），
  整文件粘贴到控制台代码编辑器即可。HTTP 触发器需设为**匿名访问**。

## 部署步骤（控制台）

1. 函数计算 FC → 创建函数（事件函数），运行时 Node.js 18，地域选华北 2（北京）。
2. 代码页：把 `fc-index.cjs` 全文粘贴为函数的 `index.js`，部署。
3. 配置 → 环境变量：
   - `DASHSCOPE_API_KEY` = 百炼 key（只配这里；不要写进任何代码/仓库）
   - `LLM_MODEL` = `qwen-flash`（可省略，默认即是；不要用 qwen-turbo，曾持续 429）
   - `ALLOWED_ORIGINS` 可省略（默认含 `https://46564645.github.io` 与本地调试端口）
4. 触发器 → 创建 HTTP 触发器，认证方式选「无需认证/匿名」，得到公网 URL。
5. 把该 URL 写入公开版构建的环境变量 `VITE_LLM_PROXY_URL` 后重新构建发布
   （本地 `.env.local` 不要写这个变量——本地构建继续直连真 key）。

## 守卫（代理层，与游戏端叠加）

- Origin 白名单外一律 403；只收 POST。
- user 消息超过 20 条的请求 400 拒绝（业主定：AI 最多对话 20 轮）。
- model 强制 `qwen-flash`、max_tokens 强制 ≤150，客户端参数说了不算。
- 单 IP 每小时 60 次（内存计数）；客户端的 Authorization 一律丢弃。
- 最后保险丝在百炼侧：账户余额上限 + 消费告警（业主的 ¥15 余额即天然上限）。

## 验证

部署后用一条与游戏同形状的请求打代理 URL：应返回 200 与家长口吻的短句；
把 Origin 换成陌生域名应 403；塞 21 条 user 消息应 400。
