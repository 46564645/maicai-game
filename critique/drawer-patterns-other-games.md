# 抽屉式收纳：其它游戏把非操作信息放哪（调研笔记）

日期：2026-11-19（Thong 11:18 拍板后补做）
事由：Thong 定了两条——① 头像条上的 🐾Go / ⚡Ea / 🛡️Ca 特质标签删掉，特质只在详情里出现、写全词；② 主界面只保留操作需要的东西，其它信息抽屉式收起来，并让他“看看其它游戏放在哪里”。本笔记只做调研参考，不改代码、不抄任何游戏的美术与代码（只借放法）。

## 结论先行（给执行侧）

1. **特质标签的归宿已定，不用再选**：点头像 → 详情抽屉（或伙伴卡）里写全词（例 "Goes along"）。这与下面三款卡牌游戏的做法一致：特质/性格类信息从不在对局主界面常驻。
2. **抽屉壳子不用新造**：游戏里已有现成壳——`WalletDrawer` 复用 `StationPopup`（横屏居中 / 竖屏底部抽屉，Esc 与 ✕ 关闭）。点头像的详情抽屉复用同一壳，手机上就是底部抽屉，桌面上是居中弹窗。
3. **主界面只留操作必需**：当前回合、能点的按钮（Buy / Done / Go to this stop / Yes / No）、金币数与菜谱进度。其余一律进抽屉或详情页。
4. **收纳判定（供执行侧扫一遍常驻界面时用）**：这条信息不看它，孩子下一步会不会点错 / 不知道点什么？会 → 留；不会 → 收进抽屉。特质、流水明细、收藏类说明都属于“不会”。

## 其它游戏的做法

### Hearthstone（炉石）
- 对局主界面只留操作必需：费用、攻击/生命、关键词图标；卡牌完整信息（规则全文、风味文字、画师、关联衍生牌）不在对局里，放在**收藏库的单卡详情页**——点一张卡进详情页看全量信息，关掉回收藏。
- 规律：**“打牌时只给打牌要用的，查资料去专门的详情页”**，详情与对局是两个场景，不叠在同一屏。

### Marvel Snap
- 对局棋盘上每张卡只显示费用、战力与技能触发词；点任意一张卡会打开**详情面板**：系列、发布日期、费用、战力、技能全文，以及精通等级、变体、胜率等收藏向数据都在这个面板里，不在棋盘上常驻。
- 规律：**点卡 → 详情面板**，面板是按需打开的一层，不挡住对局流程，关掉即回棋盘。

### Pokémon TCG Pocket
- 点卡 → **全屏放大的卡牌详情视图**（可旋转看卡，✕ 或 Esc 关闭）；收藏与对战是分开的两个 halves，详情只在收藏/查看场景出现；稀有全画幅卡点按还会进入沉浸动画场景。
- 规律：**详情 = 单独一层全屏视图**，看完即关；主界面永远不为“看看而已”的信息让位。

### 通用抽屉 / 底部抽屉模式（设计系统口径）
- 抽屉（Drawer / Bottom Sheet）是**从屏幕边缘滑入的覆盖层**，放次要任务，不把人带离当前场景；背后有遮罩、底下内容仍可见一半，保持方向感；下滑 / 点遮罩 / ✕ / Esc 都能关。
- 适用：次要操作、筛选、详情查看；不适用：需要全神贯注的关键决策（那种用居中弹窗）、内容极少时（用气泡即可）。
- 手机上常用底部抽屉 + 拖拽手柄，可停在 30% / 60% / 100% 几个高度；桌面上常用右侧边栏式检查器面板。
- 游戏 HUD 的同一条原则：从空界面开始，只加能证明自己值得常驻的元素；操作时才出现的提示、按需打开的信息都不常驻。

## 对照本游戏现状

- 特质标签目前在三处常驻渲染：`BotCard.tsx`（伙伴卡上的 `bot-trait`）、`Game.tsx` 头像条（约 L361）与思考气泡（约 L419、L833）。按 Thong 的决定：头像条与气泡上的删；伙伴卡（`ProfileCard`，详情视图）里保留并写全词；再加一个“点头像开详情抽屉”的入口，抽屉里同样写全词。
- 已有抽屉先例：`WalletDrawer`（钱包：菜谱进度、金币流水、先等等夹、待付夹）就是抽屉式收纳的既有实现，复用 `StationPopup` 壳。
